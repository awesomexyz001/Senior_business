## 0. 한 줄 요약

**혼자 사는 50~64세가 동네에서 같은 사람 6~8명과 8주 동안 매주 만나는 '시즌 소모임' 웹서비스입니다.** 모임 자체가 서로의 안부망이 되도록 설계하고, 이후 돌싱 만남 트랙과 '혼자 대비' 기능을 붙입니다.

- 1차 제품: **웹(모바일 우선 PWA) + 카카오 알림톡**. 앱스토어 앱은 6개월 뒤 판단합니다.
- 돈: 참가자가 시즌 참가비를 냅니다. 2년차부터 지자체 위탁(B2G)을 붙입니다.

## 1. 왜 이 서비스인가: 데이터 → 설계 연결

| 데이터가 말한 것 | 근거 | 그래서 제품은 |
|---|---|---|
| 외로움을 가르는 축은 나이가 아니라 **배우자 상실** | 외롭다: 사별 58.9%, 이혼 57.1%, 배우자 있음 35.5% (2025 사회조사) [근거] | 대상을 나이가 아니라 **'혼자 사는 사람'**으로 정의 |
| **40대 남성 외로움 40.6%로 전 집단 최고**, 40~59세 1인가구는 남성 비중 60.5% → 약 69% | KB 2026, 장래가구추계 [근거] | 남성이 오는 **'역할·기술' 이름표 모임**(요리, 집수리, 걷기, 파크골프 입문) |
| 원하는 것은 하루짜리 클래스가 아니라 **정기적으로 소속될 곳** | 시놀 대표 인터뷰, 50대 동호회 참여 11.5%로 최고 [근거] | **같은 멤버·같은 요일·8주** 고정 시즌제 |
| 밤에는 익명 전화(외로움안녕120, 중장년이 17시~새벽 1시), 낮의 대면 공간은 65세 이상이 66% | 서울시 [근거] | 밤의 '첫 손들기'에서 **낮의 정기 모임으로 넘어가는 다리**를 제품이 맡음 |
| 일상 안부는 공공이 약 30만 가구에 무료 제공, 지불 의향 41.8%. AI 콜은 "죽었나 확인하는 전화"로 받아들여짐 | 노인실태조사 등 [근거] | 안부 확인 단독 상품은 만들지 않음. **모임 출석이 곧 안부**가 되는 '관계형 안부'만 무료 기능으로 넣음 |
| 재혼의 **95%가 이혼 후 재혼**. 평균 재혼 연령 남 51.9세, 여 47.5세. 결혼중개 피해구제 3년 연속 증가 | 2025 혼인통계, 소비자원 [근거] | 2단계 **'돌싱 시즌'**: 미팅이 아니라 활동 기반, 신원 인증과 사기 예방이 핵심 가치 |
| 도시 근로 **50대 1인가구 55.5%가 입원·수술 때 보호자 없음을 걱정** | KB 2026 [근거] | 3단계 **'혼자 대비' 키트**: 비상연락인 지정, 보호자 카드, 병원 동행 업체 연결(직접 인력 운영 X) |
| 50·60대 여가 장벽 1위는 **경제적 부담**(56~57%), 월 여가비 50대 20.0만 원·60대 17.9만 원 | 2025 사회조사, 2024 국민여가활동조사 [근거] | 시즌 참가비를 **월 여가비의 10~20% 수준**으로 책정 〔가정〕 |

### 의도적으로 하지 않는 것
- **안부 센서·AI 안부전화 단독 상품:** 공공이 무료로 제공하고, 지불 신호가 약합니다.
- **돌봄·간병 인력 직접 운영:** 해외 사례(Papa)에서 본 안전사고 책임이 큽니다. 소규모 팀이 감당하기 어렵습니다.
- **결혼정보회사형 1:1 매칭:** 고가, 환불 분쟁, 법 규제가 걸립니다.
- **경로당형 공간 운영:** 이미 공급 과잉입니다(경로당 이용률 26.5%).

## 2. 첫 사용자(가설)

> 니즈 탐색 단계이므로 '확정 타겟'이 아니라 **첫 시즌을 열 사람**입니다. 유형을 바꿔도 제품 골격(시즌 모임 + 관계형 안부)은 그대로 씁니다.

| 구분 | 첫 사용자 A | 첫 사용자 B |
|---|---|---|
| 누구 | 56세 이혼 남성, 혼자 산 지 6년, 직장인(서울 마포구) | 58세 비혼 또는 돌싱 여성, 직장인 또는 은퇴 직전(서울 성동구) |
| 상황 | 퇴근 후 TV, 주말엔 말할 사람 없음. 동호회는 "아저씨들 술자리" 같아 꺼림 | 친구 모임은 기혼자 중심으로 멀어짐. 새로운 사람은 만나고 싶지만 안전이 걱정 |
| 근거 | 40·50대 남성 외로움 최고, 이혼자 외로움 57.1%, 50·60대 남성 고독사 53.9% [근거] | 여성은 법적 재혼보다 동반자 관계 선호(1위), 50대 이상이 통신금융사기 피해 51.7% [근거] |
| 지금 하는 것 | 아무것도 안 함, 가끔 당근모임 둘러봄 | 당근모임·시놀 가입했다가 영업·이성 목적 회원에 질려 탈퇴 |
| 원하는 것 〔가정〕 | 이름표가 '모임'이 아니라 '배우기'인 것(요리, 수리), 술 없는 정기 일정 | 신원이 확인된 사람들, 같은 멤버, 운영자가 있는 모임 |
| 지불 〔가정〕 | 8주 시즌 4.9만~7.9만 원(재료비 별도) | 동일. 돌싱 시즌은 9.9만 원까지 |

**초기 지역:** 서울 2~3개 구(마포·성동·송파 후보)입니다. 1인가구 밀도가 높고 대중교통 30분 안에 모일 수 있어야 합니다. 시즌 모임은 **동네 밀도**가 생명이라 전국 동시 오픈은 하지 않습니다.
**성비 원칙:** 남성 40% 이상을 목표로 합니다. 시놀은 회원의 약 70%가 남성인데, 우리는 반대로 남성이 오지 않는 문제를 먼저 풀어야 합니다.

## 3. 서비스 구조 (3단계)

```
[1단계 MVP]  시즌 소모임 ── 관계형 안부(무료) ── 밤의 한마디(익명 첫 접점)
                  │
[2단계]      돌싱 시즌(활동 기반 만남) ── 신원·혼인상태 인증 ── 사기 예방·'관계 이후' 가이드
                  │
[3단계]      혼자 대비 키트 ── 비상연락인·보호자 카드 ── 병원 동행·유품정리 업체 연결 ── 지자체 위탁
```

### 1단계 MVP 기능 (출시 범위)

| 기능 | 설명 | 데이터 연결 |
|---|---|---|
| **시즌 탐색·신청** | 동네·요일·이름표(요리/걷기/집수리/사진/파크골프 입문)로 고르기. 정원 6~8명, 8주, 주 1회 2시간 | 정기 소속 수요, 남성용 '역할·기술' 이름표 (H3) |
| **본인인증 + 결제** | 휴대폰 본인인증(실명·나이·성별 확인), 카드·간편결제 | 50~69세의 50.9%가 간편결제를 주 결제수단으로 사용 [근거] |
| **카카오 알림톡 일정·출석** | 모임 전날 알림, 당일 "참석/불참" 한 번 누르기. 앱 설치 불필요 | 보호자·요양보호사용 설계 교훈(설치 없는 구조) |
| **관계형 안부** | 주 1회 "이번 주 잘 지냈어요" 버튼. 2주 연속 무응답이면 호스트가 먼저 연락하고, 원하면 지정 연락인에게도 알림 | 안부 단독 상품 대신 관계 기반 안부 (피해야 할 니즈의 '남는 틈') |
| **호스트 도구** | 출석 명단, 멤버 연락(번호 비공개 중계), 다음 주 공지, 신고 처리 | 운영 부담 최소화 |
| **밤의 한마디** | 저녁 6시~새벽 1시에만 열리는 익명 한 줄 게시판. 댓글 대신 "나도 그래요"만 허용하고, 근처에서 열리는 시즌을 추천 | 밤의 익명 접점에서 낮의 모임으로 가는 다리 (H3) |
| **안전 장치** | 신고·차단, 영업·다단계·금전 요구 금지 규칙, 첫 모임은 공개 장소에서만 | 모임 내 영업·이성 목적 반복 문제 [근거] |
| **접근성** | 기본 글자 18px 이상, 큰 버튼, 고대비, 한 화면에 한 가지 행동 | 50~60대 시력·디지털 숙련도 편차 |

### 2단계: 돌싱 시즌 (MVP 지표 통과 후, 법률 검토 필수)
- **형식:** 일반 시즌과 같은 활동 기반 모임입니다. 참가자 전원이 돌싱 또는 비혼 싱글이고 성비를 맞춥니다. 1:1 매칭은 하지 않습니다.
- **인증:** 본인인증 필수. 혼인관계증명서로 '현재 배우자 없음'을 확인하는 선택 인증을 둡니다.
- **사기 예방:** 금전 요청 감지 안내, 첫 3회 모임 전 개인 연락처 교환 비권장 가이드.
- **'관계 이후' 가이드:** 상속(법정상속분), 유족연금 소멸(재혼·사실혼), 자녀 대화법. [근거: 니즈 보고서 재혼 섹션의 민법·국민연금법 조항]
- ⚠ **결혼중개업법:** 성비를 맞춘 돌싱 모임이 '국내결혼중개업'(시·군·구 신고, 보증보험 등)에 해당할 수 있습니다. **출시 전 변호사 확인이 필요하며**, 확인 전에는 '만남 주선', '매칭' 같은 표현을 쓰지 않습니다. 〔가정: 법 적용 범위는 미확인〕

### 3단계: 혼자 대비 키트 (2년차)
- **비상연락인 지정과 '보호자 카드':** 지갑과 휴대폰 잠금화면에 넣는 카드입니다. 지병, 복용약, 연락인을 적습니다. 건강정보는 사용자 기기 안에만 저장합니다. 〔가정〕
- **연결만 하는 제휴:** 병원 동행, 가사, 유품정리 업체를 소개하고 제휴 수수료를 받습니다. 인력을 직접 운영하지 않습니다.
- **지자체 위탁(B2G):** 1년치 운영 데이터(외로움 점수 변화, 출석·재등록률)를 들고 서울시 '외로움 없는 서울'과 구청 1인가구지원센터에 프로그램 위탁을 제안합니다.

## 4. 사용자 흐름 (1단계)

```
① 유입
   네이버 블로그·카페 글 / 구청 1인가구지원센터 게시 / 밤의 한마디 / 지인 초대
        ↓
② 랜딩(시즌 목록) ─ 동네·요일·이름표 필터, 로그인 없이 구경 가능
        ↓
③ 카카오 로그인 → 휴대폰 본인인증 → 짧은 프로필(닉네임, 동네, 관심 이름표 3개)
        ↓
④ 시즌 신청 + 결제 ─ 첫 모임 전 100% 환불, 2회차 이후 회차 비례 환불
        ↓
⑤ 알림톡: 시즌 확정 · 전날 알림 · 당일 출석 버튼
        ↓
⑥ 매주 모임 + 주간 안부 버튼
        ↓
⑦ 8주차: 만족도 1문항 + 외로움 1문항 → 다음 시즌 '같은 멤버로 계속하기' 추천
```

**핵심 설계:** 8주가 끝나면 같은 멤버로 계속할지 묻습니다. 재등록이 곧 소속감이고 매출입니다.

## 5. 수익 모델과 숫자 감각 〔모두 가정〕

| 항목 | 가정 |
|---|---|
| 시즌 참가비 | 8주 4.9만~7.9만 원(회당 약 6~10천 원). 재료비·장소비는 실비로 따로 받음 |
| 호스트 보상 | 참가비의 40%(파트너 강사) 또는 참가비 면제(멤버 호스트) |
| 플랫폼 몫 | 시즌당 6~8명 × 6.4만 원 × 60% ≈ 23~31만 원 |
| 목표(1년차 말) | 서울 3개 구, 동시 운영 시즌 40개, 재등록률 50% → 월 매출 약 1,500만~2,000만 원 |
| 2년차 추가 | 돌싱 시즌(9.9만 원), 제휴 수수료, 지자체 위탁 |

**가격 근거:** 50대 월 여가비 20.0만 원, 60대 17.9만 원 [근거]. 시놀 단체 미팅 19.9만 원, 월 구독 2.5만 원 [근거, 전문]. 국내 지불 의향 설문은 없으므로 **컨시어지 단계의 사전 결제로 직접 확인**합니다.

## 6. 기술 계획

### 앱이냐 웹이냐 → **웹(PWA) 먼저**
- 앱스토어 심사, 업데이트 배포, 설치 장벽이 없습니다.
- 알림은 **카카오 알림톡**으로 보냅니다. 50~60대는 푸시 알림보다 카톡을 더 확실히 봅니다.
- PWA로 홈 화면에 아이콘을 추가할 수 있습니다.
- 앱 전환 기준: 재방문 사용자가 월 3,000명을 넘고, 푸시 알림·위치 기능이 필요해질 때입니다.

### 스택(제안)
| 영역 | 선택 | 이유 |
|---|---|---|
| 프론트·서버 | Next.js(App Router) + TypeScript | 웹 한 벌로 화면과 API 처리, 레퍼런스 많음 |
| DB·인증 | PostgreSQL(Supabase 등 관리형) | 무료 시작 가능, 행 단위 접근 제어 |
| 로그인 | 카카오 로그인(OAuth) | 50~60대 카카오 계정 보유율이 높음 〔가정〕 |
| 본인인증·결제 | PortOne(휴대폰 본인인증 + PG 연동) | 한 곳에서 인증과 결제 처리 |
| 알림 | 카카오 알림톡(솔라피 등 발송 대행) | 템플릿 심사 필요, 건당 수 원~십수 원 |
| 배포 | Vercel 또는 국내 클라우드 | 개인정보 국외 이전 고지 여부 확인 필요 〔가정〕 |

## 7. 실행 로드맵 (16주)

| 기간 | 할 일 | 통과 기준 (미달 시 조치) |
|---|---|---|
| **1~4주: 컨시어지 검증** (개발 0) | 랜딩 페이지 1장 + 신청 폼 + 수동 결제(계좌·결제링크). 2개 구에서 시즌 2개를 엽니다(요리 1, 걷기 1, 각 8명). 니즈 보고서 질문 은행으로 참가자 인터뷰 | **사전 결제 12명 이상, 남성 40% 이상.** 미달하면 이름표·가격·요일을 바꿔 한 번 더 열고, 그래도 미달이면 H1(보호자 대행) 컨셉으로 전환 검토 |
| **5~10주: MVP 개발** | 시즌 목록·신청·본인인증·결제·알림톡 출석·주간 안부·호스트 화면·신고 | 결제부터 출석까지 수동 작업 0 |
| **9~12주: 시즌 운영 1기** | 3개 구 6개 시즌 동시 운영, 밤의 한마디 오픈 | **완주율(6/8회 이상 출석) 70%, 주간 안부 응답률 80%** |
| **13~16주: 재등록·확장 판단** | 다음 시즌 재등록 오픈, 외로움 1문항 사전·사후 비교. 돌싱 시즌은 법률 자문 착수 | **재등록률 40% 이상.** 통과하면 돌싱 시즌 준비와 지자체 제안서 작성, 미달하면 이탈 인터뷰 후 형식(주기·인원·이름표) 수정 |

**가장 중요한 단일 지표:** 8주 뒤 **같은 멤버로 다시 돈을 내는가**(재등록률)입니다.
